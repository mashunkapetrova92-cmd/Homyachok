# Хомячок. Специальный выпуск №34

Сайт-подарок к 34-летию. Всё лежит в одной папке:

```
index.html      — сам сайт (тексты, оформление, награды, архив)
photos/         — все фотографии
video/          — видео-послание (message.mp4) и его обложка (poster.jpg)
```

Чтобы посмотреть сайт на компьютере, открой `index.html` двойным щелчком.

---

## Как заменить или добавить фотографии

**Фото на обложке.** Замени файл `photos/cover.jpg` своим, назови новый файл так же: `cover.jpg`.

**Фото у письма.** Это файл `photos/portrait.jpg`, меняется так же.

**Архив.** Открой `index.html` в любом текстовом редакторе (Блокнот, TextEdit, VS Code) и найди строку `const ARCHIVE = [`. Каждая строка ниже — одно фото:

```js
{src:"photos/forest.jpg", w:1600, h:1200, tag:"Лес", cap:"Подпись под фото"},
```

- `src` — путь к файлу в папке `photos`
- `w` и `h` — ширина и высота фото в пикселях (их видно в свойствах файла)
- `tag` — короткая метка над подписью (дата, место)
- `cap` — подпись
- `feature:true` — необязательно, делает подпись крупнее

Чтобы добавить фото, положи файл в `photos` и скопируй любую строку, поменяв значения. Чтобы убрать фото, удали его строку. Порядок строк = порядок фото на сайте. Лучше не загружать фото шире 1600 пикселей, так сайт быстрее откроется на телефоне.

## Как изменить тексты

Все тексты находятся в `index.html`. Ищи их поиском (Ctrl+F / Cmd+F):

| Что меняем | Что искать |
|---|---|
| Подзаголовок обложки | `ПОДЗАГОЛОВОК ОБЛОЖКИ` |
| Награды: название и «за что» | `const AWARDS = [` — поля `title` и `why` |
| Текст письма | `ТЕКСТ ПИСЬМА` — каждый абзац в своих `<p> … </p>` |
| Бегущая строка | `const tickWords` |
| Видео в конверте | `ВИДЕО-ПОСЛАНИЕ` — или просто замени файл `video/message.mp4` |

Меняй только текст между кавычками или между тегами, не трогая сами кавычки, `<p>` и `</p>`. После правки сохрани файл и обнови страницу в браузере.

## Как бесплатно выложить сайт по ссылке (GitHub Pages)

1. Зайди на [github.com](https://github.com) под своим аккаунтом.
2. Нажми **+** в правом верхнем углу → **New repository**.
3. Название, например, `homyachok` (без имён и фамилий: оно войдёт в ссылку). Выбери **Public** → **Create repository**.
4. На странице нового репозитория нажми ссылку **uploading an existing file**.
5. Перетащи в окно **содержимое** этой папки: файл `index.html` и папки `photos` и `video` целиком. Внизу нажми **Commit changes**. Видео весит около 13 МБ, загрузка займёт минуту.
6. Открой **Settings → Pages**. В блоке **Branch** выбери `main` и папку `/ (root)`, нажми **Save**.
7. Через 1–2 минуты вверху этой же страницы появится ссылка вида
   `https://ИМЯ-АККАУНТА.github.io/homyachok/`. Её и отправляй.

Чтобы потом что-то поправить, открой нужный файл в репозитории, нажми карандаш (**Edit**), измени и нажми **Commit changes**. Через минуту сайт обновится.

**Важно:** на GitHub Pages сайт публичный. Любой, у кого есть ссылка, увидит фото и видео (в том числе фото детей). В поисковиках он сам по себе не появится, но ссылку стоит отправлять только самым близким.

**Запасной вариант без GitHub:** зайди на [app.netlify.com/drop](https://app.netlify.com/drop) и перетащи туда всю папку. Сайт сразу получит ссылку.
